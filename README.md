# יצירת תמונות ריאליסטיות ב-GitHub Actions

ריפו קטן שמייצר תמונות דמויות צילום עם המודל RealVisXL V5.0 (מבוסס SDXL), על השרתים של GitHub, בלי לגעת במחשב המקומי.

## איך זה עובד

- **משימה = קובץ:** כל קובץ ב-`jobs/` מתאר משימה: יצירה מטקסט (`txt2img`), או צביעה מחדש של אזור מסומן בתמונה קיימת (`inpaint`, לתמונות "לפני" שמתיישרות בדיוק עם ה"אחרי").
- **דחיפה מפעילה:** דחיפה של קובץ משימה מפעילה את התהליך האוטומטי `generate`. הוא מוריד את המודל, מייצר כל משימה שעוד אין לה תוצאות, ושומר את התמונות ב-`outputs/<שם המשימה>/`.
- **בלי כרטיס מסך:** לשרתים החינמיים של GitHub אין כרטיס מסך, ולכן כל תמונה לוקחת בערך 10–30 דקות.

## קבצים

| קובץ | מה יש בו |
|---|---|
| `gen.py` | היצירה עצמה. רץ על כרטיס מסך אם יש, ואחרת על המעבד ב-bfloat16 |
| `run_jobs.py` | מריץ את המשימות שעוד לא הורצו |
| `.github/workflows/generate.yml` | התהליך האוטומטי ב-GitHub |
| `BRIEF.md` | ההנחיות המלאות למשימה הנוכחית (תמונות לפני ואחרי) |
| `final/` | התמונות הסופיות |
